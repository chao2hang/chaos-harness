# `@deepseek-ai/dsh-host-web-auth`

[English](README.md) | 中文

WebServer 传输层的令牌认证。`required` 会在激活前解析配置的凭据，向未认证浏览器 GET 请求提供最小登录页，并通过 HttpOnly、SameSite Cookie 维护随机内存会话。守卫覆盖静态资源、`/plugins`、`/api` 与 WebSocket 升级；`/auth/*` 保持公开。

`off` 保留本地回环开发行为。该插件不会持久化令牌或会话，也不提供静态存储加密。

## 模型体验

无，因为该包只保护浏览器传输，不注册面向模型的内容。

#### KV Cache 影响

无；认证状态由浏览器 Cookie 携带，不会改变模型请求。

## 已知限制与后续工作

- **会话生命周期** — 会话只存在于活动进程中，因此进程重启后浏览器必须再次认证。
- **凭据存储** — 此包解析配置的凭据，但不加密静态凭据；配置的凭据提供方负责存储保护。
